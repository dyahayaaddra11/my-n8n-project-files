# Estate Lead Bot Frontend

React + Vite frontend foundation for the Estate Lead Bot.

## Current status

This is the initial frontend foundation. Product-specific screens and integrations will be implemented from the project's specification documents.

## Run locally

```bash
npm install
npm run dev
```

## Structure

- `src/App.jsx` — application shell and initial dashboard
- `src/main.jsx` — React entry point
- `src/styles.css` — responsive styling
- `index.html` — Vite entry document
